📥 Where data is read from
Item list, sections & colours Tab 4 · Stock Ledger

Pick plan (existing picks & dates) Tab 2 · Pick Plan
Beneficiary records Tab 1 · Beneficiary Database
Household qty defaults per pick Tab 9 · Template Config
Partners, dietary & allergy options Tab 10 · Reference Data
📤 Where data is written to
New & edited pick plans Tab 2 · Pick Plan
New beneficiary records Tab 1 · Beneficiary Database
Pick status updates (Prepared / Collected) Tab 2 · Pick Plan (col H Status)
⚙️ How to configure via the spreadsheet
Add / rename / reorder items Tab 4 · Stock Ledger — col A (name), col E (section)
Change section colour in pick grid Tab 4 · Stock Ledger — col D (hex colour)
Change portion label shown to packer Tab 5a · Item Config — col F (Portion Label)
Set default quantities by household size Tab 9 · Template Config — cols D–I
Add beneficiary partners / dietary options Tab 10 · Reference Data — cols E, G, I
Portion labels: The small label shown under each item name in the pick grid (e.g. "500g bag") comes from Tab 5a · Item Config, col F. Edit that column to change what packers see. The quantity number itself is always in portions — quantities are converted upstream when deliveries are logged.
